# Roblox-mode ribbon icons

Original 32x32 SVG glyphs for the Roblox UI mode ribbon, part dropdown, edit tab and
dragger-mode popup. Flat light strokes (`#e0e0e0`) on transparent; axis accents
`#e5484d` / `#46a758` / `#3e63dd` where meaningful, matching Godot's dark editor theme.
No Roblox logos or copied Roblox art.
