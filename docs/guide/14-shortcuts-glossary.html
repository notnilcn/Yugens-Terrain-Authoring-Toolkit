Three rules before you press anything

1 · Put the mouse over the 3D view

Godot sends most keys to whatever panel is under the mouse. The terrain tools' number keys, the builder's E / I / Alt+3 and friends, and F (focus) only work while the pointer is over the 3D view. If the builder ignores [ / ], click a part in the view first so it has focus. (page 10)

2 · The same key means different things in different places

While a terrain is selected, 1–9 switch terrain tools and don't reach editor shortcuts like Ctrl+1; click another node first. In the builder's Roblox layout, 1–5 are Select / Move / Scale / Rotate / Transform and F is zoom-to. In the MST / Modeler layouts, 1–4 are selection modes and F fills a hole. Ctrl+L locks a node in Godot, but toggles local / world handles in the Roblox layout.

3 · F8 is Stop, not Run

In Roblox Studio, F8 is Run and Shift+F5 is Stop. In Godot, F8 stops the game. F6 plays the scene you're editing, and F5 plays the project's Main Scene. (page 13)

Godot & add-on terms

Words you'll see on every page, explained without jargon. The chips split Godot's own words from this add-on's.

Node

Godot

One thing in a scene: a light, a camera, a terrain, a mesh. Like a Roblox Instance. Nodes sit in a tree, and a child moves with its parent.

Scene

Godot

A tree of nodes saved as one file. Your whole level is a scene, and a single reusable prop can be a scene too. Like a place, or a Model you can reuse.

.tscn

Godot · file

The file a scene is saved in. Double-click one in the FileSystem dock to open it in a tab.

Root node

Godot

The top node of a scene (e.g. World). Everything else is under it. Like the Workspace.

Instance

Godot

A copy of a saved scene dropped into another scene with Instance Child Scene (chain icon). Edit the original and every instance updates. Like inserting a Package.

Scene dock

Godot · left

The tree of nodes in the open scene: add, rename, reparent, hide and lock them. Your Explorer.

Inspector

Godot · right

Every property of the selected node, in collapsible groups. Your Properties window.

FileSystem dock

Godot · bottom left

The files in your project folder: scenes, models, textures. Shares the corner with the History tab.

res://

Godot · path

"The project folder". res://tutorial/guide/first_world.tscn means the file tutorial/guide/first_world.tscn inside your project.

Dock

Godot

A panel around the edges of the editor (Scene, FileSystem, Inspector, History, Import). Docks can be moved and tabbed together.

Viewport / 3D view

Godot · centre

The big 3D picture where you look at and edit your world. Most shortcuts need the mouse over it.

Main-screen buttons

Godot · top centre

2D · 3D · Script · Game · Asset Store. They swap the centre area. Stay in 3D.

Resource

Godot

A piece of data that isn't a node: a material, a texture, a mesh, the terrain's data. It can live inside a scene or in its own file (.res / .tres) and be shared.

.res / .tres

Godot · file

Saved resources (binary / text). The terrain's chunk data is often a .res next to the scene. Keep it with the scene when you copy things.

Gizmo

Godot

The coloured arrows, rings and boxes for moving, rotating and scaling the selected node (W / E / R). Red = X, green = Y (up), blue = Z.

Transform

Godot · Inspector

A node's Position, Rotation and Scale. Type exact numbers here instead of dragging.

Node3D

Godot · node type

The basic 3D node: a position in space with children. Use one as an empty "folder" or a scene root.

MeshInstance3D

Godot · node type

A node that shows a 3D model (a mesh). Imported models are made of these.

Camera3D

Godot · node type

The camera the game looks through. Adding the pixel Renderer adds one for you.

DirectionalLight3D (Sun)

Godot · node type

Sunlight from one direction. A new scene has none, so it's dark until you add Sky & Clouds or a preset.

WorldEnvironment

Godot · node type

The sky, ambient light and fog for the whole scene, like Roblox's Lighting + Atmosphere.

StaticBody3D + CollisionShape3D

Godot · node types

Make something solid: the body says "this doesn't move", the shape says how big the solid part is. Like CanCollide.

CharacterBody3D

Godot · node type

A body moved by code that collides with the world, used by the demo player. If it starts inside the ground, it falls through.

Material / StandardMaterial3D

Godot · resource

How a surface looks: colour (Albedo), Metallic, Roughness and textures.

Shader

Godot

A small program that draws a surface or effect. The pixel look is built from shaders; you only change their settings.

GDExtension

Godot

A compiled add-on that Godot loads at start-up. MST is one, so it's always on and listed under Project Settings → GDExtension, not Plugins.

Plugin (EditorPlugin)

Godot

The other kind of add-on, switched on in Project Settings → Plugins. That list is empty here, and that's normal.

Project Settings

Godot · Project menu

Settings saved with this game: Main Scene, window size, renderer, import options.

Editor Settings

Godot · Editor menu

Your personal editor preferences, shared by all projects. The builder layout (MST / Modeler / Roblox) is stored here.

Main Scene

Godot · Project Settings

The scene the game starts in. F5 and exported builds run it. In this project it's the demo island.

Import dock / Reimport

Godot · top left

Settings for how a model or image file is converted (e.g. Root Scale). Change them, then press Reimport.

glTF / GLB

Godot · file format

The recommended 3D model format (.gltf text or .glb single file). Y is up.

Export template

Godot · export

The ready-made game runtime Godot packs your project into. Install it once (Manage Export Templates) before Export Project works.

History dock

Godot · bottom left

The list of every undoable action, newest at the top.

Output panel

Godot · bottom

Messages, warnings (yellow) and errors (red). Read the top line of a red message first.

Config warning ⚠

Godot · Scene dock

A yellow triangle on a node means "this isn't set up yet". Hover it for the reason.

Perspective / Orthogonal

Godot · 3D view

Normal 3D view vs a flat, no-depth view. Clicking the nav cube switches to Orthogonal; Kp 5 switches back.

Remote / Local

Godot · Scene dock

While the game runs, Remote shows the live game's node tree; Local is your saved scene.

MarchingSquaresTerrain

Add-on · node

The terrain node. Select it and the terrain toolbar, strip and hint bar appear.

Chunk

Add-on · terrain

One square tile of ground (32 cells × 2 m = 64 m by default). A new terrain has none: add them with the Chunks tool (8).

Cell

Add-on · terrain

One square (or hex / triangle) of the terrain grid. Heights, textures and tints are stored per cell.

Terrain data (MarchingSquaresTerrainData)

Add-on · resource

The resource holding all chunk heights, paint and foliage. Shown in the Inspector as Contents.

Strip

Add-on · bottom of the 3D view

The row of settings for the current tool or selected effect (Size, Strength, Pixel Size…).

Hint bar

Add-on · bottom left of the 3D view

One line listing the current tool's mouse and key actions. Read it whenever you switch tools.

Grid type

Add-on · Settings

Square, Triangle, Hexagon or Hex Rings. Some features (Terraced smoothing, waterfalls) need a non-square grid.

Surroundings

Add-on · terrain

Endless procedural land drawn around your chunks in the editor, so it's hard to see where your map ends. The running game shows the real edge.

Scatter item (PixelScatterItem)

Add-on · resource

One entry in the Foliage palette: its Form or model, density, size and slope rules.

Erosion node

Add-on · node

MarchingSquaresErosion, a child of the terrain. Press Erode to weather the whole map in one undo step.

PixelRenderer

Add-on · node

Turns the 3D scene into pixel art: Pixel Size, outlines, palette, god rays. Added by Pixel World → Renderer (with a Camera).

Pixel Preview

Add-on · 3D view menu bar

Shows the editor view through the pixel renderer. Some scenes open with it already on.

Animate

Add-on · 3D view menu bar

Runs clouds, water, weather, birds and fire in the editor. Off keeps the editor light; edits still show at once. The game always animates.

Pixel World

Add-on · menu + right panel

Where you add effects (Renderer, Sky & Clouds, Day / Night, Weather, Water…), apply Lighting Presets and Wire Sun / Env Refs.

Wire Sun / Env Refs

Add-on · Pixel World

Reconnects effects to the scene's Sun and WorldEnvironment. Use it when an effect shows ⚠.

PixelObject

Add-on · node

A parent node that gives the models under it the pixel look and its own outline settings.

PixelBuilderMesh

Add-on · node

A builder "part": a mesh you insert, shape and edit face by face (pages 9 and 10).

Roblox UI

Add-on · 3D view toolbar

Switches the builder to a Studio-style Model / Edit ribbon with Studio handles and shortcuts.

Builder layouts

Add-on · Editor Settings

MST (left toolbar + panels), Modeler (top toolbar + popups), Roblox (ribbon). Same tools, different keys.

Material slot

Add-on · builder

A material on a builder mesh that faces can use. A new part has none, so painting colours the whole mesh until you add slots.

Adjust panel

Add-on · builder

The small panel that appears after Extrude, Inset, Bevel or Loop Cut so you can tweak the amount. Esc cancels.

Lighting Preset

Add-on · Pixel World

Dawn, Noon, Dusk, Night, Storm or Snow: sets time, sky, weather and god rays in one undoable click.

Check yourself

You pressed Ctrl+1 to get back to one viewport but the terrain switched to the Brush instead. Why?

While the terrain is selected, number keys go to the terrain tools. Click another node (e.g. the scene root) first, then press Ctrl+1.

In the Roblox layout, how do you switch to Face mode? And in the MST layout?

Roblox layout: Alt+2 (bare 2 is the Move tool). MST / Modeler: plain 2.

What's Roblox's "Anchored" in this add-on?

There's an Anchor button, but it means "sit on and follow the terrain", not "freeze physics".

What does res:// mean?

The project folder. Every path that starts with it is a file inside your project.
