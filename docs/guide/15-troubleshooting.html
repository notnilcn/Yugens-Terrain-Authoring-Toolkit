Troubleshooting & FAQ

Something isn't doing what you expected? Find the symptom below. Each card says what's going on, how to fix it, and which chapter explains it in full.

ReferenceSymptom → cause → fixGodot 4.7

How to use this page

  • Type a word from what you see, such as dark, falls, grey, wheel or template, or pick an area chip.
  • Each card shows Why (the cause) and Fix (what to do), plus a link to the page that covers it.
  • Most mistakes undo with Ctrl+Z: every stroke, chunk, stamp, preset or boolean is one step.
  • The FAQ at the bottom answers the bigger "can I…?" questions.
The five most common first-day problems

1) A new terrain has no chunks, so there's nothing to sculpt. 2) A new scene is dark until you add a sun. 3) Number keys switch terrain tools while the terrain is selected. 4) Shortcuts only work with the mouse over the 3D view. 5) A player you add falls through the ground if you don't move it up first.

Editor & basics

I added a terrain and nothing shows up / I can't sculpt

Editor & basics · ⚠ on the terrain node
Why
A new MarchingSquaresTerrain starts with 0 chunks. There's no ground yet, and the node shows a ⚠ warning.
Fix
Choose Chunks (8), look from above (Kp 7) and click a green + marker. Each one adds a 64 m tile.

Sculpting · Level, Paint, Foliage, Tint
Why

On an older build of the add-on? Problems that are already fixed

These bugs were fixed while this guide was being written. You won't see them on the current build, and some older clips in the guide still show them. If you do see one, update the add-on to the latest build.

  • Shift+wheel or Alt+wheel zoomed the camera while resizing or rotating a terrain brush. Now only the brush changes.
  • Ctrl+wheel hints were wrong. Strength didn't respond on Smooth / Raise-Lower / Gradient, and Level's hint claimed a Ctrl+wheel it doesn't have. Both are fixed.
  • New builder parts looked dark and see-through until given a material. They now arrive as solid Medium Stone Grey, the same grey as a new Part in Roblox Studio, and no longer copy the mesh you have selected. The current clips on page 9 show the fixed look.
  • Insert Part gave an error after switching scene tabs.
  • Lighting presets left fog on after cycling through them (a washed-out mint-green look).
  • Changing Weather with Animate off froze half-blended. It now applies instantly.
  • Scenes opened with the editor camera about 400 m away from the terrain.

FAQ

Do I need to write code?

No. Everything in this guide (terrain, the pixel look, effects, modelling, the playable demo character) is done with tools, menus and the Inspector.

Do I need to install or enable the add-on?

No. It's already in this project at res://addons/MarchingSquaresTerrain/ and, being a GDExtension, it's always on. You need Godot 4.7 or newer.

Can I undo anything?

Yes. Ctrl+Z undoes, Ctrl+Shift+Z redoes. A brush stroke, stamp, paste, erosion, chunk add / remove, lighting preset, slider drag or boolean is one step each. The History dock lists them.

Where is my terrain saved?

In a terrain data resource (the Inspector's Contents). It's either stored inside the .tscn or kept as a .res file beside it; in Baked / Runtime storage it's one file per chunk in a Data Directory. Ctrl+S saves the scene and its data together. See page 6.

Does the Roblox UI switch change the terrain tools?

No. It only switches the builder into the Studio-style Model / Edit ribbon. Terrain tools, the Foliage palette and the Chunks / Settings strips look the same either way.

Is the terrain infinite like Roblox's?

No. It's made of chunks you add one by one. The endless land you see in the editor is just "Surroundings" decoration; the game shows your real island.

Square, hexagon or triangle grid: which should I use?

Square is the simplest and what the tutorials use. Hex and triangle grids unlock terraced smoothing, Grid Aligned brushes and water pools with waterfalls. Look at demo/hex_island.tscn to see one. Choose before you add chunks; some grid settings lock afterwards.

Can I get my terrain into Roblox Studio or Blender?

Yes: Settings (9) → Storage → Export GLB bakes it into one mesh with a texture atlas. Import that in Studio's 3D Importer (it arrives as a MeshPart) or Blender's glTF importer. Save it outside the project folder. Builder props export too (right-click → Export ▸).

Can I bring my Roblox builds into Godot?

Yes: in Studio use Export Selection to get an .obj + .mtl, and drop both into your project (e.g. res://models/). See page 11.

Which 3D formats work best?

glTF / GLB, which imports as a scene with materials and textures. OBJ works too, as a mesh. FBX and .blend need extra setup in Editor Settings.

How do I make the game start in my world?

Project → Project Settings… → Application → Run → Main Scene → pick your scene. Then F5 and exported builds start there.

How do I send my game to a friend?

Install export templates once, then Project → Export… → choose or add a platform preset → Export Project…, and zip the output folder. See page 13.

The editor feels slow. What helps?

Turn Animate off when you aren't watching effects move, so the editor only redraws when something changes.

Why do some clips in the guide look different from my screen?

A few were recorded before small fixes (see older builds). Panel positions also shift with window size and editor scale; look for controls by name.
