# Plants, Trees and Props

There are two different ways to put objects on the terrain:

1. **Foliage** paints many small things that follow the terrain: grass, trees, rocks, flowers.
2. **Placed props** are single, important objects: a statue, a bridge, a house, the player. You place these as normal nodes and wrap them in a `PixelObject`.

Use Foliage for anything you want hundreds of. Use a placed prop for anything the player will remember.

## The Foliage tool

Select the terrain and click **Foliage** (`5`). The right-side panel becomes the **Foliage** palette.

![[foliage-panel.png]]

The palette lists:

- **Grass** — the terrain's grass layer.
- The terrain's existing **scatter items** (Tree, Pine, Bush, Rock, Flowers, or custom ones).
- **+ Tree**, **+ Pine**, **+ Bush**, **+ Rock**, **+ Flowers** — buttons that create a built-in item if the terrain does not have it yet.
- **Add Mesh / Scene…** — use your own model as a paint brush.
- **Edit** / **Remove** for the selected item.

### Painting

1. Click one or more items in the palette. `Ctrl` + click or `Shift` + click selects several.
2. Drag on the ground with the **left mouse button**. A single click places at least one prop.
3. Drag with the **right mouse button**, or `Shift` + left, to erase the selected items.
4. **Density** controls how full a stroke is. `1` places props almost touching; lower values are sparser.
5. `Shift` + wheel changes the brush size.

> [!tip]
> If a stroke looks too sparse, paint over the same spot again. Each new stroke fills the gaps instead of replacing what is already there.

### Fill Terrain

**Fill Terrain** scatters the selected items over the whole terrain using each item's own rules: ground textures, slope limit, height range, clusters, and density. This is how you get a forest in one click.

**Clear** removes every instance of the selected items. Both are undoable.

> [!warning]
> Fill Terrain replaces the current instances of those items. If you hand-placed a special tree and then fill the same Tree item, your hand-placed tree is replaced too.

### Erase All

With **Erase All** ticked, right-dragging removes *every* prop under the brush, not only the selected ones. This is useful for cleaning a building site, and dangerous everywhere else.

## Grass is different

Grass is not a prop you place one by one. It is generated by the terrain:

- It only grows on texture slots with **Has grass** ticked (in the Paint panel).
- **Settings → Grass** controls the blade size, density, wind and minimum height.
- The Foliage palette's **Grass** entry lets you paint grass on or off with the brush.

If you paint a dirt path with the Paint tool, grass disappears there automatically, because Dirt has no grass.

## Making your own foliage item

1. Put a 3D model in the project: drag a `.glb`, `.gltf`, `.fbx` or `.obj` into the FileSystem panel.
2. Select the terrain and choose **Foliage**.
3. Click **Add Mesh / Scene…** and pick the model's scene.
4. A new item appears in the palette. Select it and click **Edit** to open its settings in the Inspector.

Useful settings on a foliage item:

| Setting | Meaning |
|---|---|
| **Density** | How many are placed in a full area. |
| **Scale Min / Max** | Random size range. |
| **Ground Slots** | Which texture slots it grows on. This is a bitmask: one checkbox per slot in the Inspector. |
| **Slope Max** | It will not grow on ground steeper than this. |
| **Cluster Scale / Threshold** | Makes patches instead of an even spread. |
| **Align To Normal** | Tilts the prop to match the ground. |
| **Y Offset** | Sinks or lifts the model. Use a small negative value for rocks. |
| **Collision** | Gives each instance a collider so the player cannot walk through it. |
| **Wind Sway** | How much it moves in the wind. |

> [!tip]
> A rock with **Y Offset** around `-0.1` and **Align To Normal** around `0.8` looks much more natural than a rock floating on the surface.

## Imported props and PixelObject

A normal 3D model does not automatically get the pixel-art look. To pixelise it:

1. Add a **PixelObject** node to the scene.
2. Drag the imported model (or a scene containing it) under the PixelObject in the Scene tree.
3. The PixelObject converts the model's materials to the pixel shader and adds it to the outline pass.

![[pixel-object-inspector.png]]

| Setting | What it does |
|---|---|
| **Pixel Size** | Block size in low-res texels. `-1` inherits. Keep it at `1` until the base look is right. |
| **Outline** | `-1` inherit, `0` off, `1` on. |
| **Outline Id** | `-1` automatic, `0–253` a specific outline group. Use explicit ids when you need coloured outlines. |
| **Outline Col.** | The outline colour for this object, if **Own Color** is on. |
| **Convert** | Converts `StandardMaterial3D` materials to the pixel shader. Leave on. |
| **Bands / Shade Floor / Rim** | Toon shading bands and edge light. |
| **Texel Snap** | Stops small objects from shimmering when the camera moves. Turn it on for characters. |
| **Profiles** | Per-part overrides for a complex object. Advanced. |

> [!warning]
> The pixel shader only uses the model's **albedo colour/texture** and emission. Normal maps, roughness and metallic maps are not carried over. If a model looks flat, that is why: paint the detail into the texture, or use the pixel look deliberately.

## Animated characters

Add the imported character under a PixelObject, then add a **PixelAnimationStepper** node next to it (not as a child of the animation player).

- Set **Fps** to `12` for the classic stop-motion look.
- Leave **Stepped** on.
- It finds the first `AnimationMixer` in the nearby subtree automatically.

The demo's fox and the walking characters use this.

## Important props need manual placement

For a house, a statue or a bridge, do not use Foliage. Instead:

1. Add the model under a `PixelObject`.
2. Move/rotate/scale it with `W`, `E`, `R`.
3. Add a `StaticBody3D` and a `CollisionShape3D` under it if the player should not walk through it. The demo's courtyard does this for every pillar, tree and fountain.
4. Save the scene.

A placed prop stays where you put it, even if the terrain changes. That is usually what you want for buildings, and usually not what you want for small rocks.

## A good workflow

1. Block out the terrain shape and paint the main ground textures.
2. Add grass. Look at it from the game camera; adjust the blade size and minimum height.
3. Fill large forests with **Fill Terrain**, using clusters.
4. Hand-paint trees near paths and landmarks so they frame the view.
5. Place the important props last, after the ground stops moving.
